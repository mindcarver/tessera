- (direction) Fast path；唯一交付物为 ARCHITECTURE-SPINE.md，面向后续实现和 Epic/Story 拆解，范围为 Tessera MVP initiative。
- (constraint) 继承 PRD：Tauri 本地桌面应用、只读、完全离线、无遥测、无云上传；MVP 只支持 Codex 与 Claude Code Agent Memory。
- (decision) AD-1 采用本地优先模块化单体 + 六边形/端口适配器范式：Tauri UI、Rust core、Provider adapters、Derived Index；防止各功能切片自行建立 HTTP 服务或直接访问文件。
- (decision) AD-2 Agent 原生文件/Provider 是唯一事实源，Tessera Derived Index 可删除、可重建；防止索引反过来成为第二事实源或驱动回写。
- (decision) AD-3 所有 Provider 通过统一 Connector port 接入，并声明 full/search_only/existence_only/unsupported 与 source kind；防止连接器把局部查询冒充完整枚举。
- (decision) AD-4 只有 Rust core 能访问确认的 Source root；WebView 只能调用 ID 化 command，不接收任意路径、SQL 或文件句柄；防止前端权限扩大和路径逃逸。
- (decision) AD-5 每个 Source 只有一个 Scan/Reconcile owner，扫描先写 staging generation，完整成功后原子切换，失败保留上一代；防止并发扫描和半套索引。
- (decision) AD-6 Canonical Memory Record 必须携带 source_id、provider、native identity、project scope、origin locator、source revision/hash、parser version 和 coverage；防止不同 Provider 结果无法解释或追溯。
- (decision) AD-7 Source lifecycle 与 Source Health 分离；索引状态、源可用性、解析覆盖度分别表达；防止一次故障被误判为用户取消或空记忆。
- (decision) AD-8 文件 watcher 只产生 dirty hint，最终状态由受限 reconcile + metadata/hash 决定；防止丢事件、乱序事件直接破坏索引一致性。
- (decision) AD-9 MVP UI 与 Rust core 使用 Tauri command/event/channel IPC，不开放 localhost HTTP；防止端口、CORS、DNS rebinding 和额外鉴权面进入单机 MVP。
- (decision) AD-10 Agent Memory 与未来 Knowledge Source 保持不同 source_kind 和领域类型，共享 registry/index/query 基础设施但不共享写入语义；防止后续 Obsidian、RAGFlow、飞书接入时污染 MVP 记忆模型。
- (version) 当前技术种子已官方核验：Tauri 2；React 19.2；Vite 8；Rust stable toolchain（版本在 rust-toolchain.toml 锁定）；rusqlite 0.39 bundled；SQLite FTS5。
- (question) 精确 Rust stable patch、Tauri CLI patch、初始 macOS 最低版本和公开分发/更新策略留给实现与发布阶段；MVP 只要求当前本机可运行。
- (decision) AD-11 所有 Agent Memory 入口必须过滤 raw chat/session/transcript，人工指令文件不进入 MVP canonical records；防止不同 Adapter 把聊天或规则误当记忆。
- (decision) AD-12 默认 file-only MVP 不产生网络、遥测或远端请求，日志不保存正文、查询词和凭据；防止下游功能引入隐私泄露或隐性云依赖。
- (decision) AD-13 连接器、扫描器和 Query Service 共享结构化 error code 与 source health 状态，单源失败不得抛成全局失败；防止各模块自行定义错误和恢复语义。
- (decision) AD-14 每个 Connector 必须具备 fixture contract、zero-source-mutation、reconcile recovery 和 unsupported-capability 测试；防止功能切片只验证 happy path 而破坏源数据或覆盖诚实。
- (decision) AD-15 定义 canonical record 粒度为 Adapter 声明的 source-native memory unit；record_id 由 source/provider/native locator+unit kind 稳定生成，parser version 只触发重解析不改变身份；防止不同 Adapter 按文件、段落或 parser 版本产生不兼容重复记录。
- (decision) AD-16 扫描状态持久化为 queued/running/staging/committing/succeeded/failed/retry，启动时回收 stale run 并保留上一 active generation；防止进程崩溃后留下不可解释的半套状态。
- (decision) AD-17 IPC DTO 必须带 api_version，查询统一 cursor+limit，扫描支持 cancellation token，进度 channel 带递增 sequence；防止 UI/核心各自解释分页、取消和事件顺序。
- (decision) AD-18 search_only 与 full 不共享完整枚举语义：search_only 结果带 observed_at/coverage/expiry，不写缺失 tombstone、不报总数、不进入 complete generation；防止远端局部结果污染完整索引。
- (decision) AD-19 Knowledge Source 使用独立 domain namespace、record identity、parser 和 migration，不可由 Agent Memory canonical table 直接承载；防止未来 Obsidian/RAGFlow/飞书接入改变 MVP 记忆语义。
- (decision) AD-20 Phase A 是单用户当前 macOS Tauri 进程：源 root 外置只读，Tessera index/config/scan state 位于 OS-managed app-data；schema migration 版本化且失败保留旧 index；诊断仅本地且脱敏，公开签名/更新/跨平台分发延期。
- (version) 技术种子更新：React 19.2.7、Vite 8.1.x、rusqlite 0.40.1 bundled；Tauri 2.x、Rust 1.97.x、SQLite bundled FTS5、notify 8.x 保持。
- (decision) ProviderAdapter 合约固定在 src-tauri/src/domain/ports/provider_adapter.rs；Codex/Claude fixtures 固定在 src-tauri/tests/fixtures/providers/{codex,claude_code}；防止各连接器自行发明端口和测试契约。
- (decision) AD-21 UI accessibility contract：所有 browse/search/inventory flows 共享语义 focus order、键盘可达 command、可读状态与空态；防止不同 UI slice 只按鼠标路径实现 NFR-13。
- (decision) AD-22 性能基准成为质量 gate：Phase 0 建立固定匿名 fixture、冷扫描/查询/内存/索引体积基线，后续变更必须报告回归并经 gate 才启用；防止各模块各自宣称足够快。
- (decision) AD-23 Browse 与 Search 共享 Query Service contract：BrowsePage 使用 cursor+limit、stable sort、EmptyState enum 和 source health metadata；防止浏览功能另造分页、空态和来源解释。
- (decision) AD-24 Scope safety default：Native Project/Provider scope 默认隔离，未知 scope 不自动合并；只有用户显式 Tessera Project mapping 才能形成 federated view；防止个人/domain/project/task 语义被猜测合并。
- (direction) Deferred verification：CSP/Markdown sanitizer、FTS5 中文搜索基线、外部 SQLite WAL mode=ro sidecar 条件、exact toolchain build check 由 Phase 0/安全测试 owner 验证；不提前进入 MVP domain。
- (decision) AD-25 Canonical artifact envelope：Adapter 必须输出 unit_kind、normalized native_locator、title/body、scope、source_revision、parser_version；file locator 使用 canonical file URI+UTF-8 line range，provider locator 必须有稳定 provider ref；无法稳定定位则 coverage 降级，不生成可定位 record。
- (decision) AD-26 Cursor 绑定 active generation：BrowsePage/SearchPage cursor 携带 generation、sort key 和 record_id；generation 变化后旧 cursor 返回 stale_cursor 并要求从新 generation 重启，防止跨代分页漏项/重复。
- (decision) AD-27 Tessera Project mapping cardinality：一个 Native Project 在一个 mapping scope 至多属于一个 active Tessera Project；只有显式 mapping 生效，未知映射不投影，projection 不复制 canonical records。
- (decision) AD-28 Scan fencing：每次 scan/reconcile 持有 source lease token 和 generation intent；取消、超时或 retry 后旧 owner 不得 commit，只有当前 token 才能切换 active generation。
- (decision) AD-29 App-data retention：Tessera 不复制 Source；Reset Index 清理 canonical body/FTS/scan runs 但保留 Source Registry 与 Tessera Project mappings；移除 Source 清理其派生 records；body 不进入 logs/snapshots；migration 原子执行并失败保留旧 index。
- (decision) Supported Artifact Matrix 固定 Codex default/CODEX_HOME memories 与 Claude default/configured auto-memory roots；未知文件统一 unsupported_artifact、仅诊断不索引；不扩展到 arbitrary roots。
- (decision) AD-21 test artifact 固定为 tests/ui/accessibility.spec.ts；AD-22 baseline 固定为 tests/benchmarks/memory-index.json，由 Phase 0 owner 生成并锁定阈值。
- (version) 技术种子进一步收窄：notify 8.2.x；Tauri 2.x 家族和 Rust 1.97.x 仍需 Phase 0 真实构建锁定 exact CLI/runtime/bundler patch。
- (decision) AD-30 native unit identity 与 display locator 分离：file line range 仅用于打开/展示；Adapter 必须提供 native_unit_id（heading path+duplicate ordinal、provider id 或 file-level fallback）并声明稳定性，无法稳定拆分时按 file-level unit，不宣称 section identity。
- (decision) AD-31 Query snapshot token 绑定 active generation、project_mapping_revision、filter/policy revision 和 sort key；任何组成 revision 变化都返回 stale_snapshot，从新快照开始分页。
- (decision) AD-32 Scan lease 使用持久单调 fencing token；commit 必须在同一事务中 compare-and-swap 当前 token+generation intent，旧 owner 即使恢复也不能提交。
- (decision) Structural seed 包含 tests/ui/accessibility.spec.ts 与 tests/benchmarks/memory-index.json，确保 NFR contract 和性能 gate 有共同目录契约。
- (decision) AD-33 Source identity lifecycle：Source confirmation 分配持久 source_id；re-discovery 按 provider+canonical root fingerprint 匹配，路径变化保留旧 Source 为 degraded 并产生新 Candidate，不自动合并或复制 mappings；只有显式 rebind 才改变 root。
- (decision) AD-34 Coherent source revision：每次 scan 先建立 source manifest/revision boundary，扫描中对文件 size/mtime/hash 做前后校验；boundary 变化则 abort/retry，不提交混合 generation；Provider DB 只在一致只读事务内读取。
