User-owned Agent
Memory Explorer

跨 Codex、Claude Code、Hermes 与 OpenClaw 的本地只读记忆资产盘点、可视化与统一搜索。

最终判断

方向成立，但首版不是“完整 Brain OS”。可构建的切口是一个本地只读的 Agent Memory Explorer：先让用户看见、理解并搜索已经散落在多个 Agent 中的记忆资产，再决定如何治理和迁移。

锁定的产品原则

  • Agent 可替换，用户数据不可被 Agent 厂商绑住。
  • 兼容不同记忆方式，不强制统一后端或分类。
  • 本地服务 + 本地 Web UI，内容默认不上云。
  • 原始聊天是事件，不是默认记忆资产。
  • 跨域默认隔离，个人核心才可默认共享。

MVP 明确排除

  • 不修改、删除、回写原始记忆。
  • 不做聊天记录搜索。
  • 不自动生成总结答案。
  • 不自动裁决冲突。
  • 不做云端托管或全量迁移。

Aha 闭环

自动发现→用户确认→只读索引→搜索真实项目→看到多个 Agent 的带出处记忆

仍需实证的弱点

  • 四类 Agent 的真实记忆位置、格式、权限与稳定读取方式尚需逐一审计。
  • “全部记忆”必须以连接器实际能力声明为准，不能先承诺完整覆盖。
  • 纯索引不能提供供应商退出保障；可导出归档属于下一阶段的关键设计。
  • 需要用真实用户数据证明统一搜索比文件搜索带来足够明显的价值。
