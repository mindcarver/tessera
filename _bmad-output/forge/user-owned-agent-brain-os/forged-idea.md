# User-owned Agent Memory Explorer

## 锁定

- Agent 是可替换的执行介质；用户拥有的记忆、知识与工作连续性必须独立存在。
- MVP 只接入 Codex、Claude Code、Hermes、OpenClaw，完全本地运行，默认不上云。
- 只读取 Agent 已保存的记忆资产；不把原始聊天记录当作记忆。
- 自动发现 → 用户确认 → 只读索引；同时支持手动路径和连接器。
- 提供来源总览、可视化浏览和跨 Agent 搜索；结果必须是可追溯的原始记忆卡片，不自动合成答案。
- 只有个人核心可默认跨领域共享；领域、项目与任务记忆默认隔离。

## 首版不做

- 不修改、删除或回写 Agent 原始记忆。
- 不强迫用户迁移、重新分类或采用统一记忆后端。
- 不做聊天记录搜索、AI 汇总、自动冲突裁决或云端托管。

## 验证闭环

安装后自动发现记忆源；用户搜索一个真实项目，能同时看到多个 Agent 中带原始出处的相关记忆，并能定位原始文件。

## 必须先验证

- 审计四类 Agent 的真实记忆位置、格式、权限和扩展记忆源。
- 明确哪些内容可直接读取、哪些只能索引、哪些无法稳定导出。
